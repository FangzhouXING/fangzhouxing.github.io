Ray Tracing 4 - Moving Box

August 22, 2020

A moving box with Golang + WebAssembly.

It runs at roughly 60 fps on Chrome. Writing code in Go is a better experience than JavaScript, at the cost of performance in this setup.

Drawing in JavaScript is GPU accelerated, while this version does extra copies between JavaScript and Go each frame. Still, it works.
